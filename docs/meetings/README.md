# Meeting archive

This folder contains durable, trip-related meeting context for future organizers.

## Structure

Each meeting has its own folder under the meeting year, named with its ISO date and a short
slug. Use:

- context.md for the meeting's purpose, confirmed outcomes, open questions, owners, and
  follow-ups.
- transcript.md for a project-focused transcript or extract when it adds useful context.

## Privacy and accuracy

The GitHub repository is public. Do not copy personal check-ins, unrelated employer or
customer information, attendee email addresses, credentials, or raw meeting metadata into it.
Preserve only content useful to the trip. Label transcript scope and transcription quality;
machine-generated speech recognition is not an authoritative record when wording is unclear.

Distinguish an organizer decision from a proposal, estimate, or AI-generated summary. Link
confirmed decisions from decisions/ and update state/trip.yml when current facts change.
Keep the original Granola note private; do not assume a private note link is suitable for a
public document.
